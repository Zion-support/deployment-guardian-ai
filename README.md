# Deployment Guardian AI

AI deployment gatekeeper that scores every release before it ships — blocking risky deploys and green-lighting safe ones.

## Features
- Pre-deploy risk scoring (change size, blast radius, history)
- Automated canary & rollout policy recommendations
- Integrates with CI/CD to gate promotions
- Incident correlation: learns from past failed deploys
